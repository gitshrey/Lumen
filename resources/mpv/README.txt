Place your LGPL-compatible Windows x64 binaries in this folder before running `npm run build:win`:
- libmpv-2.dll
- mpv.exe
- ffprobe.exe

Official sources:
- mpv / libmpv: https://mpv.io/ and https://github.com/mpv-player/mpv/releases
- FFmpeg: https://ffmpeg.org/ and https://www.ffmpeg.org/legal.html

See LICENSING.md in the project root before distributing binaries.
