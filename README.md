## What's New in 3.0

- **Warm Obsidian Liquid Glass UI**: Eye-comfort dark & light themes, refractive sidebar, next-gen Play Prism icon, and a **Low-End PC Mode** in Settings.
- **12 Customizable Subtitle Animations**: Zero-jump word-synced presets (*Hormozi Pop*, *Liquid Glass Pill*, *Aurora Sweep*, *Kinetic Blur Focus*, *Wave Bounce*, *Cyber Glitch*, *Cinema Serif*, *Box Spotlight*, *Karaoke*, *Neon Glow*, *Typewriter*, *Classic*) with live preview, size slider (`16px–56px`), custom text & highlight colors, vertical offset, and **Dual Subtitles**.
- **Pro Playback Engine**: Powered by [mpv](https://mpv.io/), [FFmpeg](https://ffmpeg.org/), [libass](https://github.com/libass/libass), and [libplacebo](https://github.com/haasn/libplacebo) with multi-language audio switching, MKV/MP4 chapter markers, timeline hover previews, 5-band Equalizer, and 200% Volume Boost.
- **Native Windows 11 Experience**: File Explorer **"Open with → Lumen Video Player"**, true OS fullscreen (`F` / `F11`), floating Picture-in-Picture, hardware media keys, hold-to-`2×` speed boost, smart **Up Next** auto-play, and update-proof activity storage (`%APPDATA%\Lumen`) for Recently Played, Resume, Playlists, and Favourites.
- **In-App Updates**: Check and install new GitHub Releases directly from **Settings → About**.

## Key Shortcuts

`Space`/`K` Play-Pause • `F`/`F11` Fullscreen • `←`/`→` Seek ±10s • `↑`/`↓` Volume • `M` Mute • `0–9` Jump % • `[`/`]` Speed • `Hold Mouse` 2× Speed • `C` Subtitles • `A` Aspect • `P` PiP • `PageUp`/`PageDown` Chapters • `Ctrl+O` Open File

## Install

1. Download the latest `Lumen-Setup-3.0.x-x64.exe` from [GitHub Releases](https://github.com/gitshrey/Lumen/releases).
2. Run the installer *(click **More info → Run anyway** if SmartScreen prompts on unsigned open-source builds)*.
3. Verify integrity anytime with the included `SHA256SUMS.txt`.
